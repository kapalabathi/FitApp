# Grafikliste Übungen (zu I-020)

## Allgemeine Vorgaben für alle Grafiken

| Punkt | Vorgabe |
|-------|---------|
| Dateiformat | SVG (bevorzugt). Ersatzweise PNG, 1024 × 1024 px, transparenter Hintergrund. |
| Seitenverhältnis | Quadratisch. Figur mittig, rundum ca. 8 % Rand. |
| Hintergrund | Transparent. Kein Raum, keine Landschaft, kein Schlagschatten. Erlaubt ist eine dünne Bodenlinie oder eine Matte. |
| Figur | Immer dieselbe Figur in allen 80 Grafiken: gleiche Proportionen, gleiche Kleidung, gleiche Farben. Geschlechtsneutral oder nach Wunsch, aber einheitlich. |
| Stil | Einfacher Comic-Stil mit klaren Konturen und flächigen Farben, ohne Verläufe und feine Details. Muss auch in 96 × 96 px noch erkennbar sein. |
| Lesbarkeit | Muss auf hellem und auf dunklem Hintergrund funktionieren: keine rein weißen oder rein schwarzen Flächen am Rand der Figur, Kontur in mittlerem Dunkelton. |
| Gesicht | Schlicht, neutral bis freundlich. Blickrichtung wie beschrieben. |
| Text | Kein Text, keine Zahlen, keine Logos in der Grafik. |
| Ansicht | „Seite" = Figur von der Seite, Kopf bzw. Blick nach rechts, sofern nichts anderes steht. „Front" = Figur schaut zum Betrachter. „Schräg" = Dreiviertelansicht von vorn. |
| Posen | „1" = eine Figur. „2" = Start- und Endposition nebeneinander in einer Grafik, links Start, rechts Ende; die Startposition etwas blasser (ca. 50 % Deckkraft). |
| Bewegungspfeile | Nur bei Grafiken mit 2 Posen: ein einzelner, geschwungener Pfeil in einer einheitlichen Akzentfarbe, der die Bewegungsrichtung zeigt. |
| Seitigkeit | Bei einseitigen Übungen wird nur eine Seite gezeichnet, wie beschrieben. |
| Geräte | Schlicht und einheitlich gezeichnet. Dieselbe Hantel, dieselbe Stange, dieselbe Box in allen Grafiken. |
| Dateiname | Exakt wie in der Spalte „Datei", Endung `.svg` bzw. `.png`. |
